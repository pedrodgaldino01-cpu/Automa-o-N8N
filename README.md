# Automação de Atendimento via WhatsApp com n8n e IA

Sistema de automação desenvolvido para realizar atendimento pelo WhatsApp utilizando n8n, Inteligência Artificial, APIs e banco de dados.

## 🚀 Objetivo do projeto

Automatizar o atendimento ao cliente, permitindo receber mensagens pelo WhatsApp, processar as solicitações com Inteligência Artificial e enviar respostas de forma automática.

## ⚙️ Tecnologias utilizadas

- n8n
- WhatsApp
- Inteligência Artificial
- APIs
- Supabase
- Webhooks
- JSON

## 🔄 Funcionamento

WhatsApp → Webhook → n8n → Agente de IA → Supabase → Resposta ao usuário

## 🤖 Principais funcionalidades

- Atendimento automatizado pelo WhatsApp
- Processamento de mensagens com IA
- Integração entre diferentes APIs
- Armazenamento de informações em banco de dados
- Automação de respostas
- Organização do fluxo de atendimento
